# Visitas Comerciales

App web (PWA) para registrar visitas de venta: fecha, hora, cliente, notas, resultado, foto de la tarjeta de visita y ruta en Google Maps. Datos sincronizados con Firebase (Auth + Firestore).

Abrir en el móvil: https://nachonac.github.io/visitas-comerciales/
En iPhone: Safari > Compartir > Añadir a pantalla de inicio.
